## 🚀 Meus projetos

### 🏥 Clínica Presença
Sistema web desenvolvido para auxiliar no gerenciamento de pacientes e no controle de presenças.

**Principais funcionalidades:**
- Cadastro e gerenciamento de pacientes
- Registro de presenças e faltas
- Organização de informações
- Interface para utilização no dia a dia

🔗 [Ver repositório](https://github.com/GomesSsx7/clinica-presenca)

### 🤖 PMESP Bot — Controle de Ponto
Bot para Discord desenvolvido em Python para automatizar o controle de presença dos integrantes de um servidor.

**Principais funcionalidades:**
- Abertura e fechamento de ponto
- Registro de horas acumuladas
- Ranking de participantes
- Painel interativo com botões
- Persistência de dados com SQLite
- Hospedagem em nuvem através do Render

**Tecnologias:** Python, SQLite, discord.py e Render.

🔗 [Ver repositório](https://github.com/GomesSsx7/pmesp-bot2)
